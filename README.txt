# একটু শোনো না… 💗 — Bengali Sorry Website

## কীভাবে চালাবি
1. `index.html`, `style.css`, `script.js` একই ফোল্ডারে রাখ।
2. `images` ফোল্ডারে নিজের ছবিগুলো রাখ:
   - `memory1.jpg`
   - `memory2.jpg`
   - `memory3.jpg`
   - `sorry.gif`
3. `music` ফোল্ডারে নিজের ব্যবহার করার অনুমতি থাকা MP3 গানটি `our-song.mp3` নামে রাখ।
4. `index.html`-এ ডাবল-ক্লিক করে Chrome-এ খোল।

## নিজের মতো করে বদলানো
- `index.html`-এ লেখা apology message নিজের ঘটনার সঙ্গে মিলিয়ে বদলে নে।
- ছবিগুলো JPG/PNG হলে ফাইলের নাম ও HTML-এর নাম মিলিয়ে রাখ।
- গান চালু করতে user-কে play button চাপতে হবে; browser autoplay আটকাতে পারে।
- Google Fonts-এর বাংলা font পেতে internet লাগবে; offline হলে browser-এর fallback font ব্যবহার হবে।

## প্রকাশ করার আগে
- ব্যক্তিগত ছবি/তথ্য অনলাইনে প্রকাশ করার আগে দুজনের privacy ভেবে নিস।
- গান প্রকাশ করার অধিকার না থাকলে website-এ MP3 আপলোড না করে YouTube/Spotify-এর বৈধ link ব্যবহার কর।
